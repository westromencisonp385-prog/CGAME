## 质量差距

### 1. 模型

- 当前候选模型有拆件和大形，但仍缺真实可见的材质层、损坏件、状态显隐、动作循环和镜头内比例调校。
- A01 在实机中被 HUD、工作区和镜头距离削弱，鲸口负形没有像概念图那样成为主视觉。
- B01 的墙体、锚点和横向冲撞没有同时进入一张可读画面。
- C04 的压力表、阀轮、密封环与修复目标没有成为玩家当前决策的视觉焦点。

### 2. 贴图与材质

- `painted_surface_atlas.png` 和透明 VFX 图集目前是候选输入，尚未绑定到正式 UV/材质状态。
- 当前实机主要依赖简单色块和基础材质，缺少概念图里的手绘边缘、功能磨损、材料差异、维修痕迹和状态遮罩。
- “高精度”要求材质分层能解释漆钢、橡胶、骨白、玻璃、混凝土、湿润和发光状态，当前还没有做到。

### 3. 渲染与关卡

- 当前环境仍是平板、少量几何块、重复树簇和低密度地标；没有达到参考图的空间层级、道具密度、前后景、接触阴影和材质变化。
- 当前雾和水流 shader 是改善项，但不能替代正式灯光、反射/粗糙度、阴影、地表贴图、桥体细节和修复前后场景重构。
- 当前特效大多是程序环、简单粒子和几何线；生成的 VFX 图集尚未进入效果分层和事件节奏。

### 4. UIUX

- 当前 HUD 仍是 debug 形态：任务面板、说明条、右侧按钮、GM 入口同时占据画面，和概念图的工单语法、留白、层级、字体和状态卡不一致。
- 当前 build 机制已经有阶段提示，但没有完成模块卡、前后对比、机制签名、代价/反制和高质量图标。
