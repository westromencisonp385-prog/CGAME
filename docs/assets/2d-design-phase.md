# 2D 设计冻结阶段：20+ 候选筛选

日期：2026-09-25。用户指出当前3D样件和概念设计稿不一致，现阶段冻结3D量产，先完成2D设计筛选。

## 当前问题

现有GLB已经达到结构样件级别：有拆件、挂点、T0–T5和VFX合同，但造型仍像精细化玩具工程车，缺少概念稿要求的巨大负形、夸张幻想比例、清楚边缘和鲜明机器性格。当前样件继续加螺栓、材质或粒子不会解决方向错误。

## 生产门槛

在用户选定方向前：

- 不制作新的正式3D底盘、敌人或群系资产。
- 不把现有GLB称作最终玩家模型。
- Godot只保留当前技术样件用于验证挂点和流程。
- 新2D候选必须能在320px缩小时读出主剪影和工程动词。
- 每个玩家机器候选必须能回答：怎么移动、主工程动作是什么、哪里装模块、成长时哪一个负形改变。
- 每个敌人候选必须能回答：危险方向是什么、玩家用什么工程动作处理、失败时有什么可复现的滑稽结果。
- 每个环境候选必须能回答：修复前哪里不能走、施工中玩家改变什么、修复后路线或服务如何变化。

## 候选分组

- A01–A08：玩家机器，重点比较底盘比例、工作头、幻想负形、驾驶室锚点和成长路线。
- B01–B06：敌人/环境对手，重点比较剪影、预告形状、工程解法和身体语言。
- C01–C06：群系/挑战/修复状态，重点比较空间构图、路线变化、地标和修复后的情绪。
- D01–D04：模块/工具/喜剧动作，重点比较主斗、磁能、钻掘、铺轨和三拍反馈。

共20张候选。候选图只用于筛选，不直接进入游戏。

## 统一2D提示约束

使用原创2D设计稿/概念设计板，不做实机截图，不做最终3D渲染，不复制参考游戏资产。保持：

- 低多边形大形的设计逻辑，但用清晰的2D形状和工业设计线稿表达。
- 大形70%、功能结构25%、装饰5%。
- 工程黄、石油蓝、骨白、珊瑚红、磁能紫、修复青绿为候选色板。
- 同一张图同时包含剪影、俯视关系、三分之四结构和少量材质色块。
- 不生成大量小字；游戏内文字之后由Godot本地化UI绘制。
- 夸张来自机械尺度、折叠、吞咽、钻掘、铺轨和修复结果，不来自失控操作。
