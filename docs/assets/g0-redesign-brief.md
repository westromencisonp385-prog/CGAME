# G0 UIUX 与 3D 重做 brief

日期：2026-09-27。状态：用户要求整体重做。本文是新的设计入口，不是正式美术规格，也不批准任何现有白模或候选资产进入量产。

## 当前结论

- 当前 Godot 界面、HUD、装配面板、结果面板和反馈动效全部视为白模。
- 当前程序化车体、鲸口 GLB、B01/C04 作者化 GLB、Weaver 候选和现有转台图全部视为白模或研究样件。
- A01 磁暴鲸口、B01 施工蟹、C04 修复泵、倒流河谷仍是玩法样板目标；它们不等于已批准的视觉方案。
- 新 UIUX 与 3D 方向通过 G0 前，暂停正式资产量产、批量 Weaver 任务和“最终美术”宣称。

## 必须保留的玩法约束

- 装配 → 预览 → 确认 → 实战组合 → 升级/变形 → 存档恢复流程不变。
- 模块必须改变操作、剪影、路线、节奏或修复关系，不能只增加 DPS。
- 玩法权威状态、碰撞、命中、资源、修复和存档不由模型动画或 UI 表现决定。
- 准备 → 接触 → 余韵三拍仍是动作和喜剧反馈的最低合同。

## 新 G0 必须交付

1. 一张整体视觉调性板：玩家车、普通敌人、设施、场景、材质、光线、色板和幽默比例。
2. 一套 UIUX 流程稿：战场 HUD、装配/预览/确认、暂停/设置、结算/恢复；标出信息优先级和手柄焦点路径。
3. 一套三视图与实机镜头稿：玩家车、B01 级普通敌人、C04 级设施；明确主负形、危险方向、退路和模块接口。
4. 一张无 VFX 的 Godot 真实镜头样板图，以及同一镜头的 UI 避让检查。
5. 一份反例清单：白模感、通用工业玩具、细节噪声、不可读 HUD、遮挡退路、装饰改变碰撞等。

## 通过条件

- 缩到 128px 仍能读出玩家车、敌人和设施的主行为剪影。
- 关闭 VFX、贴图和声音后，玩家仍能指出目标、危险、工程解法和可走退路。
- UI 不遮住工作区、目标、退路或关键预告；键鼠和手柄焦点顺序都可说明。
- 模块预览能同时表达安装前后轮廓、动作变化、收益、代价和组合关系。
- 新方向确认前，所有输出标记为 `whitebox`、`proposal` 或 `candidate`，不使用 `integrated` / `final`。

## 待用户对齐

- 整体调性采用哪一组参考：工业童话、荒诞手工机械、卡通设施剧场，或新的方向。
- UI 信息密度和喜剧表现的优先级。
- 是否保留当前斜俯视镜头，或一起重做镜头高度、透视和战场占比。
