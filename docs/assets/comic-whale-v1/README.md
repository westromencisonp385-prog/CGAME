# 磁暴鲸口：图形漫画成长板 v1

这张成长板记录一个完整流派的三个视觉阶段：

1. **小型回收车**：小驾驶室、短履带、半张鲸口，负责收集和基础铲击。
2. **磁暴鲸口**：同一驾驶室和底盘保留，巨大上下颚形成主负形，负责聚拢、压缩和投送。
3. **超大型回收工厂**：鲸口成为前方吞吐门，后方展开分类滚筒、吊臂和回收设施，承担大规模吞噬、分类和战场清理。

输入图是图形漫画风格概念设计，包含作者化比例、硬边明暗、复杂机械结构和大色块。它不是最终 3D 模型，也不替代 Blender 拆件、枢轴、碰撞、材质、动作或 Godot 实机验收。

本批敌人输入：

- N01 液压路障蟹：横向筑墙和侧冲。
- N02 刀轮废料犬：近身冲锋和回收块咬合。
- N03 弹药罐背包炮虫：远程三连发和开阀弱点。
- N04 磁轨维修蜂：飞行支援线和可截获维修目标。
- E01 高压雷炉河马：重甲冲锋和泄压窗口。
- E02 反极浮环猎手：磁环牵引、反弹和核心打断。
- BOSS01 断城巨神：超大型施工战斗机器人，三阶段拆护甲、拆武器、打核心。

每张输入图和 QA 结论见 [N-enemies-manifest.json](N-enemies-manifest.json) 与 [E-boss-manifest.json](E-boss-manifest.json)。它们都是 `concept_input/candidate`，需要经过 Blender/Godot 结构、动作、碰撞、LOD 和实机镜头验收。

7 件概念图已经通过 Weaver `图生360 → 图生高模` 生成 3D candidate；结构统计见 [weaver-candidate-report.json](weaver-candidate-report.json)。当前结果全部是单网格、无 UV、无动作，保留作形体参考，下一步由 Blender 作者化拆件。

生产约束：

- 三个阶段共享玩家身份锚点：驾驶室、履带、主磁环和前向工作区。
- 阶段变化必须增加负形、关节或工作规则，不能只缩放车体。
- 所有动作按准备→接触→余韵制作，接触时刻由权威 gameplay 事件决定。
- 超大型阶段可让镜头动态拉远，但必须保留危险、退路和目标 HUD 的可读性。
