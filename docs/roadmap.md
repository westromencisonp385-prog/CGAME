## 现行质量门

正式内容必须同时满足：风格化、高精度、去 AI 感、多种多样。项目规划至少 100 个可区分 build；每个 build 要改变机制或决策成本，并留下结构、动作、VFX、UI、声音和存档证据。细则见 [项目全局指导](project-guidance.md)。

任何模型、贴图、UI、VFX、场景或 build 都按以下状态流转：

`whitebox → proposal → candidate → integrated → final`

测试通过只能证明功能行为。只有真实镜头、无 VFX 对照、贴图/材质、动作事件、碰撞/LOD、720p/1080p 和缺陷复测都通过，才允许进入 `integrated`。

本轮生产身份单独记录：**概念 PNG**只证明造型、剪影、色材和动作意图；**3D candidate**只证明模型/材质/骨骼/动作候选可进入评审；**真实游戏集成**必须在 Godot 实际镜头中通过碰撞、动作事件、LOD、UI 避让和缺陷复测。当前允许前两层开始生产，第三层尚未完成。

## Phase 0：证据与口径重置（已完成）

交付：

- 正确使用 AssetRipper 对 Wanderburg 原始包重新导出并生成可回查清单；
- 直接读取 Steam 商店页与用户提供的概念截图；
- 明确概念图是视觉真源，当前 Godot 白模不能作为目标；
- 建立全局质量门、G1 缺口报告和 UIUX/3D 重做 brief。

退出条件：所有文档不再把错误导出、白模截图或候选 GLB 写成正式资产。

## Phase 1：首轮概念与 G1 资产镜头（当前阶段）

目标：沿图形漫画方向 C，在同一真实 Godot 镜头内，让磁暴流派玩家车、普通/精英敌人、BOSS01、设施、河岸和 UI 形成一张可读的高质量画面。生产顺序明确区分概念 PNG、3D candidate 和真实游戏集成。

顺序：

1. 以 A01/B01/C04 概念 PNG 为真源，补齐磁暴鲸口幼体→回收工厂→超大型吞噬机械的三阶段剪影、色材和动作分镜。
2. 产出 N01–N04、E01–E02 与 BOSS01 的概念 PNG，明确危险方向、弱点、反制和漫画式打击构图。
3. 由 Blender/程序/Weaver 生成 3D candidate，保持拆件、枢轴、材质意图和动作阶段；候选结果不直接进入正式集成。
4. 在 Godot 建立真实相机、动态拉远、灯光、材质状态、碰撞、LOD、敌人预告和 UI 避让样板；GM 信息保持独立。
5. 输出同一镜头的基础/成长、无 VFX/有 VFX、各敌人波次与 Boss 阶段、720p/1080p 对照图。

G1 退出条件：图形漫画主形和材质语言在实机中可读；玩家、敌人预告、BOSS 弱点、C04 阀轮/压力表/桥和退路不被 UI 遮挡；关闭 VFX 仍能读出危险和战斗解法；模型、贴图、动作、碰撞、LOD、存档和性能有证据。通过前仍按 `candidate` 记录。

## Phase 2：G2 战斗爽感与喜剧动作

目标：完成首轮 15 分钟流派的可重复战斗切片：从“聚拢 → 鲸口压缩 → 投送 → 物理连锁”进入普通/精英混战，最后用三阶段战斗击败 BOSS01；战后再演出泵站恢复。

必须同时验证：

- F 规则的目标资格、载荷、伤害、修复事务和存档结果；
- F 规则的普通敌人、精英反制、Boss 弱点、阶段结算和战后修复结果；
- P 表现的准备、接触、余韵、烟尘、连锁碰撞、镜头拉远、声音和 UI 反馈；
- 有/无 VFX、暂停、慢放、读档和低画质的一致性。

G2 退出条件：陌生玩家无需讲解就能说出自己做了什么、为什么清掉敌群或击败 Boss，并愿意换一个 build 再试；首领胜利不是修复按钮触发。

## Phase 3：100+ build 目录与机制矩阵

先建立目录，再扩内容。10 个机制家族各规划至少 10 个行为不同的 build：聚拢/磁吸、水电、惯性/冲撞、载荷/压缩、钻掘/地形、变形/折叠、修复/建设、诱导/反制、热量/节奏、经济/回收。

每条目录记录：机制、输入节奏、核心/辅助模块、形态阶段、成本、反制、视觉拆件、VFX/SFX、UI 卡面、测试场景、存档字段和状态。目录未完成前不把内容数量写成已实现。

## Phase 4：M1 首轮完整小合同

G2 通过后，将 15 分钟磁暴流派接入完整倒流河谷合同：资源、构筑、普通敌人、精英、BOSS01、战后修复结果、局外蓝图、营地服务、胜负、结算事务、F5/F9 和独立 Windows 导出。每新增一类资产都从 G1/G2 的模板复制，而不是重新发明风格。

## Phase 5：M2 垂直切片与发布准备

只有 M1 的真实试玩、制作成本、性能和存档证据稳定后，才扩第二/第三群系、首领梯度、局外蓝图、Steam 功能、本地化、Deck/手柄和 release 验收。商店素材必须来自通过的实机切片，概念图不能冒充截图。

## 当前不做

- 不把旧白模、旧 GLB、Weaver 输出或漂亮转台图直接升格为正式资源；
- 不复制 Wanderburg 的模型、贴图、音频、脚本或导出工程；
- 不在首轮流派和 G1/G2 质量门未通过时批量生产 100 个 build 或扩三群系；
- 不用测试通过、导入通过或 AssetRipper 数量替代真实镜头质量验收；
- 不清理历史导出、旧计划或未决 wayfinder 票据，除非用户在收尾汇报后明确确认。
