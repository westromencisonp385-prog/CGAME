# AssetRipper 引用矩阵

更新时间：2026-09-24。此矩阵是 `研究：建立模块与载具引用矩阵` 票据的研究结果。它只整理仓库已有的导出证据，不把 IL2CPP 空方法、命名相似或资源存在当成运行时算法。

## 置信度

- **observed**：可在导出序列化文件、仓库证据 JSON 或已读取的字段/节点中回查。
- **inferred**：由 observed 结构提出的原创实现启发或关系假设，尚未通过参考游戏运行观察证明。
- **unknown**：当前证据不足，必须由本作原型或参考运行观察决定。

来源入口：

- [结构证据](../evidence/reference_asset_contract.json)（Prefab 路径、SHA-256、对象数、节点与行号）。
- [导出清单](../evidence/assetripper_export_inventory.json)（场景、Prefab、纹理、脚本数量与路径统计）。
- [深度分析](assetripper-analysis.md)（字段签名与边界解释）。
- [视觉研究](../evidence/reference_visual_study.json)（色板、材质、VFX、相机等直接观察）。
