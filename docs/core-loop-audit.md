# 核心玩法循环审计

日期：2026-09-23。审计对象包括已验证的 M0 和 M1 小合同，不把完整战役或 M2 内容提前包装成完成。

## 结论

**M0 核心循环成立，M1 小合同也成立；下一步可以扩展内容，但要沿同一闭环推进。**

当前可运行的闭环是：

1. 接近废料或敌人。
2. 用铲斗完成工程动作，获得装载资源或改变敌人状态。
3. 收集材料让车辆进入二阶段。
4. 进入改装台选择合法构筑。
5. 用磁暴鲸构筑把轻型目标聚拢、打包，再一次释放。
6. 携带材料启动水泵，世界进入修复状态。
7. 清除威胁并完成合同。
8. 保存、读取或重试，状态仍然一致。

公共 seam 测试为 core_loop_flow.gd，以玩家动作和 main.gm.execute/get_state 为观察入口；它不是对私有方法的镜像测试。当前固定 Godot 4.7.2 的全套测试也包含 whale_pack_flow.gd、contract_flow.gd、save_flow.gd 和 presentation_flow.gd。M1 额外使用 core_loop_m1_flow.gd，验证修复前后真实碰撞门禁、奖励幂等、局内重置、GM 存档和普通 F5/F9。

## 尚未成立的商业循环部分

这些是完整战役和内容量产的缺口，不是 M0/M1 小合同失败：

- 当前只实现一处修复路线和一个蓝图 ID；多个合同、营地服务和完整奖励树尚未完成。
- 蓝图已经持久化，但还没有把全部蓝图接入正式升级池和完整经济。
- 三个机器谱系、正式怪物行为、首领和三群系尚是世界圣经中的提案。

因此下一刀应复制这条 M1 闭环到第二份合同，再接入一个真实蓝图效果和营地服务。当前不新增第四套机器或更多怪物来掩盖这些缺口。

## 体验优化规则

任何新增内容都必须回答：玩家做了哪个工程动作、改变了哪一个权威状态、获得了什么可读收益、下一次出击如何因此不同。笑点和 VFX 只能放大这个因果，不能替代它。若新增内容不能通过同一公共 seam 或真实 GPU/试玩证据，就保持为设定提案。
