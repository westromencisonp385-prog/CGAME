# 敌人与群系视觉生产计划 v1

日期：2026-09-26
状态：G0 提案，供一车一敌一段河岸样板使用；不授权批量量产。
依据：[工业童话低多边形风格锁定](../assets/style-lock-industrial-folk-v1.md)、[2D 候选库](../assets/2d-candidates/README.md)、[世界圣经](../world-bible.md)。本计划只规定视觉生产与接入，不新增玩法合同。

## 1. 视觉目标

敌人必须在正交斜俯视、720p 实机镜头中先被读成“工程问题”，再被读成角色。读图顺序固定为：主行为剪影 → 预告方向/危险区 → 可用工程解法 → 材质与笑点。关掉贴图、VFX 和声音后，仍须从轮廓知道它是在横移筑墙、喷压、导电、投递、重排装甲或吸入物件。

群系不是给敌人换一套皮肤。每个群系只增加一条地形/天气规则、一种环境重音和一套修复前后对照；敌人沿用同一套材质槽、挂点命名和动作三拍。C01 倒流河谷是首个样板：青绿水道、赭黄泵站、骨白湿地边缘；危险用番茄红，修复用青绿色发光。

## 2. 普通→精英→超大 Boss 剪影梯度

| 层级 | 相对玩家车体高度/宽度 | 屏幕占比（实机目标） | 负形与轮廓 | 材质槽/色重音 | 动作与预告 |
|---|---:|---:|---|---|---|
| 普通敌人 | 0.35–0.65×高度，0.5–0.9×宽度 | 3–6%画面宽；群体合计不超过25% | 一个主行为形状，至少一个可穿透负形；横向、竖向、悬浮三类不要混在同一波 | 3槽：主体、橡胶/暗部、行为件；1个番茄红或紫色重音 | 准备≤0.7s、接触、余韵；预告线/扇形/小环，颜色只指危险性质 |
| 精英 | 0.8–1.2×高度，0.9–1.4×宽度 | 7–12%画面宽；同屏最多2只 | 普通剪影上加一个会改变战术的“大件”或二次负形；不能靠加螺栓变精英 | 4槽：主体、暗部、装甲/工作件、状态重音；保留群系色 | 准备1.0–1.4s，预告有阶段变化；至少两段可识别动作（例如架墙→换墙面） |
| 超大 Boss | 1.8–3.0×玩家车体高度，1.5–2.5×宽度；占地按碰撞另测 | 18–32%画面宽；主体不遮住玩家、退路和目标HUD | 三块以上可分离大形，中心必须有稳定负形/弱点窗；远景仍读出“工程设施失控” | 5槽上限：主体、暗部、功能件、装甲/地表接触、发光状态；最多2个重音色 | 预告姿态先于伤害；准备≥1.5s，接触、余韵各有清楚停顿；每阶段只改一件大形或负形 |

比例是生产包的起始包络，不等于最终碰撞。镜头占比用 Godot 真 GPU 截图验收；若 Boss 让玩家看不到退路，先缩轮廓或移镜头，不用 VFX 补救。

### 负形规则

- 普通敌人：一个缺口、窗或腿间空隙，128px 缩略图仍可见。
- 精英：两个负形形成“读行为”的方向，例如 B02 锅炉河马的压力口 + 热气锥空隙。
- Boss：中心负形是阶段/弱点的视觉锚，不在每个阶段重画整张轮廓。负形边缘用骨白或橡胶黑包边，避免与地表混淆。
- 同屏不要出现两个拥有相同主负形的敌人；通过横/竖/圆环方向错开群体语言。

## 3. 候选 B01–B06 的生产分层

| 候选 | 主剪影与工程动词 | 建议层级 | 生产抓手 |
|---|---|---|---|
| B01 倒车蟹路障 | 横向蟹脚 + 宽挡板；侧移筑墙 | 普通（可升精英） | Blender 手工定脚/挡板负形；Weaver 仅作材质/比例探索；墙体为独立拆件 |
| B02 锅炉河马 | 低矮圆锅炉 + 压力环；喷压/热气锥 | 精英 | Blender 手工做锅炉、阀门和压力环枢轴；Weaver 可图生高模草稿，必须重拓扑 |
| B03 截止电鳗 | 长条导管 + 紫色电网；跳跃/导电水洼 | 普通 | Weaver 图生只做四视图参考/UV纹理候选；电网、导电脚点和尾段必须 Blender/Godot 原生 |
| B04 拆迁鸽无人机 | 上窄下宽翼板 + 红色警示标；偷取修复标记 | 普通空中 | Blender 手工控制翼片、挂点和俯视厚度；Weaver 不负责可飞 rig |
| B05 条款巨像 | 竖向层叠装甲板；重排受击面 | 超大 Boss 候选 | Blender 手工拆 3–5 块装甲和旋转枢轴；Weaver 可做单块板纹理/形状探索，LOD需手工 |
| B06 垃圾台风 | 中心压缩机 + 环形悬挂垃圾；旋转/吸入 | 超大 Boss/环境 Boss 候选 | 中心压缩机和碰撞代理 Blender 手工；外围垃圾可实例化，风圈和轨迹由 Godot shader/粒子 |

首个 G1 只做 B01 或 B03 之一；世界圣经建议施工蟹 + 逆坡水母，但 B01 是最容易证明“剪影→工程解法”的敌人。

## 4. 群系与环境候选 C01–C06 的画面规则

| 候选 | 画面主语 | 颜色/材质限制 | 必做状态层 |
|---|---|---|---|
| C01 折叠河流 | 折线水道、泵站、桥 | 石油蓝水体、赭黄设施、青绿修复；水面流动只用 Godot shader | 修复前逆流、修复中导流、修复后顺流；桥碰撞三态共用坐标 |
| C02 天气售后 | 风机、盐地、被吹走的标件 | 骨白盐地 + 灰紫阴影，番茄红只标风向/危险 | 无风/起风/风暴；风向箭头和道具轨迹不能靠文字 |
| C03 城市需要呼吸 | 叠层道路、通风井、捷径 | 石油蓝/灰紫建筑，青绿窗光表示通风恢复 | 堵塞/排气/通风；上下层边界必须有连续护栏和退路 |
| C04 维修泵剖面 | 泵体、密封环、阀轮、压力表 | 5槽上限，阀轮与管口保持骨白高对比 | 停机/加压/稳定；三状态共享挂点 |
| C05 设施护送 | 移动泵站和维修点链 | 设施用赭黄，护送路径用青绿短线 | 出发/受损/到达；路径不能遮敌人预告 |
| C06 营地服务板 | 车库、蓝图板、桥 | 低对比背景，功能卡保留六色板 | 未修复/服务中/已恢复；只做呈现验证，不作为战斗环境 |

环境资产用大块、边缘和路口做分层，避免把小道具当群系识别。群系状态变化至少有一个真实通路变化、一个设施动作和一个远景色块变化。

## 5. 状态/动作层与 Godot 挂点

每个敌人至少交付以下状态表：`idle`、`telegraph`、`contact_or_window`、`recovery_or_exit`、`disabled/dead`。权威事件决定接触时刻；动画只消费事件，不修改判定。

统一节点/挂点命名（根节点下）：

- `EnemyRoot`：碰撞代理、朝向和群系层级的唯一根。
- `Visual/Body`、`Visual/BehaviorPart_*`：可见拆件；每个拆件可独立显隐/材质重音。
- `Sockets/TelegraphOrigin`、`Sockets/TelegraphAim`：预告起点与指向；预告几何由 Godot 生成。
- `Sockets/Contact`、`Sockets/Weakpoint_*`：接触/弱点事件；不得用网格中心猜位置。
- `Sockets/VfxAnchor_*`、`Sockets/Sfx_*`：持续、爆发、余韵各至少一个锚点。
- `Sockets/Drop`、`Sockets/RepairTarget`：掉落或工程解法目标；仅在功能已确认时保留。

三拍动作最低要求：准备姿态拉开主负形 → 接触姿态压缩/指向目标 → 余韵姿态回弹并露出解法窗口。暂停、慢放、读档和关闭 VFX 后，状态仍须一致。

### 预告形状词典

- 线：路径、导电或冲撞方向；沿地面，端点留在镜头内。
- 扇：喷压、墙体推移或区域禁行；扇根固定在 `TelegraphOrigin`。
- 环：吸入、爆压或中心安全区；环宽不超过主体最窄负形的一半。
- 网格/板：可重排装甲或施工墙；每块板对应一个独立弱点/拆件。
- 阴影云：风暴/垃圾台风；边缘先出现，中心窗口保持干净。

预告颜色只使用番茄红（即将伤害/封路）、紫色（磁/电/状态）、青绿色（修复/安全窗口）三类；不能用亮度变化代替形状。

## 6. 拆件、LOD、Weaver 与 Blender 分工

### Weaver 可承担

- 单主体四视图或图生高模的形状探索，前提是输入图无文字、无道具并保留风格锚点。
- 共享材质/UV 纹理候选、低频手绘色块、单块装甲或环境道具。
- LOD 初稿和拓扑建议，不能替代最终碰撞、枢轴或状态拆件检查。

### 必须 Blender 手工

- 主轮廓、负形、比例、碰撞代理和镜头包络。
- 所有可动件的父子关系、枢轴、拆件命名、弱点与 `Telegraph*`/`Contact` 挂点。
- Boss 阶段拆装、装甲重排、可见状态层和 LOD 最终面数。
- 四视图不一致、生成网格破面、穿插、材质槽超过5个时的重拓扑与重建。

### Godot 负责

- 原生预告线/扇/环/网格、材质参数、粒子、颜色状态、相机和 UI 避让。
- 运行时显隐、三拍事件消费、低画质降级和 VFX 并发预算；不在网格里烘入冷却或攻击电弧。

## 7. 三个超出挖掘机范畴的 Boss 外形方向

1. **条款巨像（B05）**：不是“大挖掘机”，而是一座会走的层叠合同档案柜。竖向板片像文件夹，中央负形是可穿行的“待审核门”；阶段切换通过三块装甲板重新排队。适合超大屏幕剪影、板片网格预告和“先处理支撑节点”的工程战术。Weaver 可探索单块板片形状/UV；整体现状、枢轴、装甲拆件和弱点必须 Blender。
2. **垃圾台风（B06）**：中心是倒置压缩机，外围是被风吸住的椅子、桶、路牌和风扇，主体没有固定腿。负形是安全内圈，危险由旋转阴影云和轨迹组成。中心碰撞、旋转轴、可掉落物实例和阶段窗口必须 Blender/Godot；Weaver 只做压缩机壳体与共享道具材质。
3. **折叠河桥兽**：由三段会走的桥、泵管和浮标组成，展开时是巨型折纸结构，折叠时变成狭长“路障”。它不依赖动物头部或挖斗，Boss 身体就是改变通路的设施。Blender 手工负责三段铰链、折叠顺序、碰撞和可见层；Weaver 可做桥板/管线风格探索；Godot 生成折叠预告线、修复色和环境水流。

三个方向都必须先过“远景轮廓 + 近景工程解法 + 退路可见”截图门槛，不能因为概念图好看直接量产。

## 8. 最小生产包与验收

每个普通敌人先交付 1 个低模 GLB、1 张真实镜头无 VFX 截图、4 个动作状态、3 个状态标记、1 个事故档案图标和 1 个声音动机占位。精英增加 1 个可拆大件与第二个预告形状；Boss 增加阶段拆件图、碰撞包络和屏幕占比截图。

验收顺序：

1. 128px 缩略图和 720p 正交实机仍能区分主剪影、负形和行为方向。
2. 关闭材质贴图、VFX、声音后，玩家能指出危险和工程解法窗口。
3. 动作按准备→接触→余韵连续播放，接触时刻与权威事件一致。
4. 镜头不遮玩家车、退路、目标HUD；Boss 同屏不让环境规则消失。
5. 模型导入无错误，材质≤5槽，拆件、挂点、碰撞、LOD 可回查。
6. 真 GPU 截图写入 `artifacts/qa/`，记录构建、镜头、画质、构筑和 GM 状态；固定帧录制不作为性能证明。

本计划的第一条执行路径是：B01 + C01 一段河岸 → 证明普通敌人剪影与施工蟹墙体预告 → 再做 B02 精英或 B05/B06 其中一个 Boss 方向。未通过 G1 前，不扩展 B03–B06 的正式 3D 量产。
