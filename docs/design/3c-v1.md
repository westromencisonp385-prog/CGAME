## 2. 原作参考（Wanderburg 序列化真值，`docs/research/wanderburg-3c-params.json`）

- 相机 `CameraRig`：正交，俯角 **45°**、偏航 0（不转）；`followLerpSpeed 3`、`leadMultiplier 1.0`（**按速度**前瞻）、`leadVectorLerpSpeed 2`；分档尺寸 `[39,45,56,72]`，缩放曲线先回缩 −0.34 再冲过 1.03；Boss 战 `+7` 尺寸、SmoothDamp 1s；Boss 登场：飞向 Boss 0.6s、缩到 0.7、停 1.25s、返回 0.75s、到达抖动 0.35s；冲刺 `boostZoomAmount −0.1`。
- 载具 `VMBaseStats`（初始底盘）：`maxVelocity 15`、`forwardShareMultiplierMinimum 0.75`（转弯时至少保留 75% 速度）、`alignmentMultiplier 30`（强抓地，几乎不侧滑）、`mouseControlRotationAngleToleranceBackward 0`（不倒车，掉头）、`forwardGimbalMaxAngle 10°`、`sidewardGimbalMaxAngle 5°`；松开摇杆即刹车（controllerCruise 废弃）。
- 比例换算：原作车身半径≈5.25、相机半高 39 → 车≈画面高度 13%；本作车身≈3.7m。

## 3. 决策

**相机**：正交 45°，不转。跟随 = 指数阻尼 k=3（帧率无关）+ **速度**前瞻（0.55×速度，阻尼 2），与瞄准完全解耦（消除 C1）。焦点钳在场地内（最多露出墙外 4m）。基础尺寸 19（车≈画面高 19%，比原作略近，因为本作是近战咬合）。进化分档按原作比例 ×[1, 1.15, 1.44, 1.85]，带回缩-冲过曲线。Boss 在场 ×1.18（SmoothDamp 1s）。Boss 登场演出照原作时序（headless 测试下关闭）。冲刺 = 尺寸冲击 −7%。震屏仍走 h/v_offset。

**操控**：坦克式朝向车。WASD/左摇杆给**世界方向**（相机不转，屏幕方向=世界方向）。车头以转向速率追向目标（静止 420°/s → 满速 280°/s），速度 = 最大速度 × 前进份额（夹角 0°→1.0，90°→0.75）。夹角 >135° 触发**甩尾掉头**（转速 ×1.6、速度降到 35%）。侧向速度按抓地 14/s 衰减（保留一点点漂移感）。0→满速 0.3s，松手 0.22s 刹停。撞墙按法向反弹 35% + 轻震。手柄径向死区 0.18 并重映射。

**瞄准与攻击**（保持现有“双摇杆”玩法，不改战斗规则）：挖斗仍咬向鼠标/右摇杆方向；模块架作为“炮塔”跟瞄准转；车身做**视觉甩头**（咬合瞬间车身向瞄准方向扭最多 35° 并前冲 0.15m，随后弹回）。地面画瞄准环 + 咬合扇形提示。

**冲刺**：方向 = 当前输入方向（无输入则车头），车头立即对齐，无敌帧不变（修 K2）。

**角色姿态**：车身偏航 = 物理朝向（不再 lerp 追速度）。纵向加速度 → 俯仰（加速抬头、刹车点头，≤8°），偏航角速度×速度 → 侧倾（≤5°），按原作 gimbal 上限取值。
