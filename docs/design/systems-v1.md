# 系统设计 v1（S 系列，2026-10-10）

依据：原作 il2cpp 结构（Unlockable / UnlockableData / QuestRunResult / RunStatisticsData / RerollEnabler / ProgressionGoals / *Unlocker）、现有代码（SelectionEngine、RunSystems、SaveV7、SelectionUI、StageDirector）、关卡设计 `docs/design/level-v1.md`。
原则：沿用已定的规范——HUD 极简、是按钮就能点、战斗中只用键盘（WASD + Q/E/R/空格 + Shift + Z/X/C）、菜单键鼠都能操作。

## 0. 总循环

```
标题 → 营地（局外） → 出发：选船长 / 选起始模块 → 一局（4 阶段） → 整局结算 → 营地
                                   ↑ 首次进入游戏自动走「新手河段」（3 分钟教学关），之后不再出现
```

| 层 | 货币 | 用途 |
|---|---|---|
| 局内 | 银币（已有 RunSystems.silver） | 重抽、阶段补给站购买 |
| 局外 | 齿轮（新，存档 `gears`） | 营地解锁新模块 / 神器 / 船长 / 载具 |

局内银币不直接带出，结算按评分换算齿轮（见第 3 节），避免“囤银币不花”的最优解。

## 1. 新手引导

### 1.1 新手河段（首次游戏强制，可在菜单“重玩教学”）

一个缩小的阶段（场地 1/3，固定种子），按“做到才前进”推进，不按时间。每步只出一句提示 + 一个地面/屏幕高亮，做完立刻给反馈（音效 + 小喊话 “好！”）。

| 步 | 提示 | 完成条件 | 教的东西 |
|---|---|---|---|
| 1 | WASD 开车 | 开到前方光圈 | 移动 |
| 2 | 靠近废料堆，鲸口会自动咬 | 咬碎 3 堆 | 自动攻击 / 回收 |
| 3 | 小怪来了，开到它旁边 | 击杀 5 只杂兵 | 自动战斗、能量球 |
| 4 | 能量满了，选一张卡（A/D 选，空格确认） | 完成第一次三选一（固定给 3 张主动模块） | 选卡 |
| 5 | 按 Q 放技能 | 用技能命中敌人 | 主动技能 |
| 6 | 红圈！按 Shift 冲过去 | 冲刺躲过一次精英预警（失败不惩罚，重来） | 冲刺 / 无敌 |
| 7 | 鲸口满了会自动投掷 | 自动投掷命中 1 次 | 投掷 |
| 8 | 小 Boss 来了 | 击败教学 Boss（鲸王幼体，血量 ×0.3，只有 1 招） | Boss / 读招 |
| 9 | 结算 | 看到结算页，领首局奖励 | 结算 / 齿轮 |

规则：

- 任何一步卡住 25 秒，提示加粗并在目标上加箭头；卡住 60 秒自动完成该步。
- 教学中玩家不会死（血量最低锁 1），但受伤照常显示，避免“不疼”。
- 随时 Esc → “跳过教学”，直接进营地。
- 完成后存档写 `tutorial_done = true`，首局奖励 30 齿轮。

### 1.2 情境提示（正式局，每种只出现一次）

首次遇到时屏幕下方出一条 4 秒提示，不暂停游戏，存档 `seen_hints` 记录：精英出现、敌巢、宝箱车、补给车、蜂群预警、Boss 出场、加时、热量过高、技能槽满、第一次进化、第一次拿神器、第一次阶段补给站。

## 2. 肉鸽卡牌管理（构筑）

### 2.1 卡的种类

| 类型 | 来源 | 上限 | 说明 |
|---|---|---|---|
| 主动模块 | 升级三选一 | 4 槽（Q/E/R/空格） | 有冷却的技能，已有 40 张 |
| 被动模块 | 每张主动模块自带被动；另有纯被动卡 | 6 槽 | 常驻加成（已有 passive 数值） |
| 模块升级 | 升级三选一 | 每张模块最高 Lv.5 | 只出已装备模块的升级 |
| 神器 | 精英 / 敌巢 / 阶段补给站 | 不限 | 已有 30 个 |
| 载具进化 | 底盘 rank 2 / 4 | 2 次 | 已有 |

### 2.2 卡池规则

- 卡池 = 已解锁的卡（营地解锁扩充卡池，原作 Unlockable 机制）。
- 权重 = 稀有度权重 × 幸运修正（已有 Luck 引擎）。
- 已装备的模块不再以“新卡”出现，改为出它的升级；满级后从池中移除。
- 羁绊标签：每张卡 1~2 个标签（火 / 电 / 冰 / 冲撞 / 召唤 / 回收）。同标签装备 2 张、4 张时触发羁绊加成；已有标签的卡出现权重 +30%，让构筑自然收敛。
- 保底：连续 5 次三选一没出过稀有以上，下一次至少 1 张稀有；每局第一次三选一必定 3 张主动模块。

### 2.3 选卡时的操作（三选一界面）

| 操作 | 键盘 | 规则 |
|---|---|---|
| 选择 | A/D 或 1/2/3，空格确认 | |
| 重抽 | R | 每局 3 次免费，之后花银币（价格按 reroll_cost_factor 递增）；击败 Boss +1 次 |
| 封印 | X（按住 0.5 秒） | 把这张卡移出本局卡池，每局 3 次 |
| 跳过 | S | 得 5 银币 + 回 5% 血 |

槽满时选了新主动模块：弹“替换哪一个”（显示 4 个槽，A/D 选，空格替换，Esc 放弃回到三选一），被替换的模块返还银币。

### 2.4 构筑面板（Tab，或暂停菜单里点“构筑”）

暂停游戏，一屏展示：4 个主动槽（等级、冷却、本局伤害）、6 个被动槽、神器列表、羁绊进度（例：火 2/4）、剩余重抽 / 封印次数。可以在这里给主动槽换位置（拖拽或 A/D + 空格交换）。原来的“改装台 B”并入这个面板。

## 3. 关卡结算

### 3.1 阶段补给站（每个阶段 Boss 倒下后，替换现在的 4 秒空档）

1. 清场演出（已有）：剩余敌人溃散，掉落吸到车上。
2. 阶段小结卡片：用时、击杀、受伤、获得银币、升了几级，评级 S/A/B/C（规则见 3.3）。
3. Boss 奖励：神器二选一（稀有池）。
4. 补给站商店（花银币，3 个格子，可重抽 1 次）：大修（回满血）、额外重抽 +2、指定模块升一级、随机神器、封印次数 +1。
5. “出发 → 阶段 N+1”。

全程暂停战斗，键鼠都能操作。

### 3.2 整局结算（通关或倒下）

一页从上到下：

- 结果标题（已有）：“四个阶段全部清场” / “倒在阶段 N · 名字”。
- 评分：阶段分 + 击杀分 + 用时分 + 无伤 / 低伤奖励，和历史最佳对比。
- 构筑回顾：最终 4 主动 + 被动 + 神器，每张卡的伤害占比条（对齐原作 ModuleStatisticsRecord）。
- 任务结算（对齐原作 QuestRunResult）：本局推进的任务，进度条 + 完成的打勾 + 奖励。
- 齿轮入账：评分 ÷ 20（失败也给，按到达阶段打折），动画滚动加到总数。
- 新解锁通知（对齐 UnlockNotification）。
- 按钮：再来一局（同船长）/ 回营地。

### 3.3 评级规则

阶段评级按“用时 + 受伤占比”：S = 用时 ≤ Boss 出场 + 45 秒且受伤 ≤ 最大血量 30%；A = 没进加时；B = 进了加时但打赢；C = 其它。

## 4. 营地（局外）

- 出发：选船长（已有 15 个，解锁制）、选起始模块（已解锁的主动模块里选 1 张，局开始就装在 Q）。
- 解锁商店：模块 / 神器 / 船长 / 载具外观，每项有齿轮价格或解锁任务（对齐原作 Unlockable：price + unlockTask，例“累计吞噬 500 个单位”解锁某模块）。
- 统计：生涯统计（已有 lifetime_statistics），最佳评分，各阶段最佳评级。
- 设置：音量、画面、按键说明、重玩教学、清除存档。

## 5. 存档（SaveV7 扩展，向后兼容）

新增字段：`tutorial_done`、`seen_hints`、`gears`、`best_score`、`stage_best_rank`、`runs_played`、`selected_captain`、`start_module`。旧档读取时补默认值；`unlocked_ids` 沿用。

## 6. 实现批次

| 批次 | 内容 | 验收 |
|---|---|---|
| S1 | 整局结算 + 阶段补给站 + 齿轮 + 评级 | 打完 / 倒下都能看到完整结算，齿轮入档，补给站每个按钮都能点 |
| S2 | 卡牌管理：封印 / 跳过 / 替换槽 / 羁绊 / 保底 / 构筑面板 | 每种操作有测试；槽满替换流程完整 |
| S3 | 新手河段 + 情境提示 | 机器人能按 9 步走完教学；每个提示只出现一次 |
| S4 | 营地：出发选择、解锁商店、统计、标题页 | 新档 → 教学 → 营地 → 出发 → 结算 → 营地 全流程跑通 |
