# 战斗设计评审与 v1 方案（2026-10-10）

依据：原作 il2cpp 结构（AttackModuleV2 / AutoTurret / Module2 槽位 / ModuleDamageContext / AttackModuleRam / KnockbackCollisionDamage / ProjectileAbsorber / DamageToSlowedEnemies / BossDeathDamageCap），原作武器数据 `docs/research/wanderburg-controls.json`（270 个攻击模块）与 `wanderburg-modules-cooldowns.json`；现有代码 `vehicle_controller.gd`、`enemy_dummy.gd`、`ability_library.gd`、`boss_patterns.gd`、`status_effects.gd`。
约束沿用：战斗只用 WASD + Q/E/R/空格 + Shift，自动攻击。

## 1. 现状（实测代码）

| 项 | 现在 |
|---|---|
| 自动输出 | 只有挖斗咬合一种：13 米锁定、0.42 秒一口、三段连击 |
| 模块 | 40 个，只有主动技能（Q/E/R/空格）。`passive_base_damage`、`auto_base_cooldown` 已从数据填好，但全工程没有任何代码使用 |
| 伤害入口 | 13 处直接调用 `take_damage`，各自算伤害；暴击只在咬合和冲刺里有；伤害不记来源 |
| 敌人防御 | 没有护甲、护盾、抗性；重型只多血。唯一克制是技能的 `anti_heavy ×1.8` |
| 元素 | 状态有 8 种，但状态之间的联动只有“潮湿 + 电” |
| 敌人 | 9 种行为（追击、跳、远程、飞、滚、冲锋、施法、逃跑、敌巢），每种只有一个攻击 |
| 玩家受伤 | 任意一次受伤后 0.4 秒无敌 |
| 冲撞 | 冲刺碰到敌人固定 20 伤害 |
| Boss | 11 个 Boss 共用 8 个招式，每个 3 招；只有阶段，没有破绽窗口 |

## 2. 缺失与问题（按影响排序）

### P0-1 模块没有自动攻击，构筑不改变战斗

原作每个模块都有两套：自动攻击（中位冷却 5 秒，1.7 到 20 秒）+ 主动技能（15 到 60 秒）。装上就自动开火，选卡直接改变屏幕上的火力。我们只有挖斗在自动打，选卡只多一个长冷却按键；打到后期，自动输出仍然只有挖斗，挖斗伤害只随底盘等级涨。结果是：升级感弱、构筑之间差别小、后期刷不动怪只能靠技能。

### P0-2 伤害没有统一管线

13 处各算各的，导致：暴击、增伤神器、模块升级只对部分来源生效；无法统计“每张卡打了多少伤害”（系统设计里的结算页和构筑面板依赖这个）；以后加护甲、元素反应要改 13 个地方。

### P1-1 无敌帧让敌人数量失去意义

每次受伤后无敌 0.4 秒，等于每秒最多挨 2.5 下。被 50 只小怪围住和被 3 只围住扣血差不多，蜂群没有威胁，精英一下重击却照样打满。

### P1-2 敌人没有防御维度，选卡没有“克制”

全部敌人只比血量，范围伤害、单体高伤、穿透、控制之间没有取舍理由。

### P1-3 纯 WASD 的操作深度不够

自动攻击 360° 自动转向，玩家只需要“躲”。原作的武器大多有朝向限制：固定朝向 32%、可转 31%、区域随机 29%、限角 7%。车头方向、侧面朝向决定火力，开车本身就是瞄准。我们缺这一层，WASD 只剩逃跑。

### P1-4 敌人角色单一

缺少逼玩家改变行为的角色：自爆车（逼你提前清或绕开）、固定炮台（逼你冲进去）、正面盾兵（逼你绕背或投掷）、增益兵（逼你优先击杀）。现有敌人只有“近身”和“远程”两种压力。

### P2-1 元素和状态没有联动

8 种状态各自独立，火、冰、电模块之间没有组合理由，系统设计里的羁绊标签也就没有战斗上的落点。

### P2-2 冲撞和车的重量感缺失

原作有按相对速度算的撞击伤害、被击飞的敌人撞到别人也会受伤。我们冲撞是固定数，车的“重”体现不出来。

### P2-3 Boss 招式重复、没有反打窗口

11 个 Boss 共用 8 个招式，打几个就重复了。只能“躲完招再打”，没有“打断/破绽 → 爆发”的节奏。

### P2-4 杂兵规模下的可读性

蜂群一次几十个伤害数字刷屏；敌我弹道颜色没有统一规范。

## 3. v1 方案

### 3.1 输出结构：每个模块 = 自动攻击 + 主动技能

- 每个模块装上即有自动攻击，按模块的 `auto_base_cooldown`、`passive_base_damage` 开火，不占按键。
- 自动攻击按槽位有朝向（对齐原作 AttackMode）：

| 槽位 | 朝向 | 例 |
|---|---|---|
| 前 | 固定朝车头，±25° 内锁定 | 前炮、弩炮、鱼叉、撞角 |
| 侧 | 固定朝左右两侧，±40° | 侧炮、喷火器 |
| 后 | 朝车尾，或沿轨迹留下效果 | 地雷、焦油、尾焰 |
| 顶 | 360° 自动转向，转速有限 | 法师、加农塔、特斯拉 |
| 乘员 | 范围内随机目标 | 狙击手、医疗兵 |

- 挖斗保留为“前槽的默认武器”，作为没装前槽武器时的兜底。
- 主动技能保持原来的 15 到 60 秒冷却，定位为“爆发和解围”。

这样开车就是瞄准：想用侧炮扫就绕圈，想用前炮就正面冲。

### 3.2 统一伤害管线

所有伤害走同一个入口，传一个伤害包：数值、来源模块、标签（火 / 冰 / 电 / 物理 / 冲撞 / 爆炸）、是否可暴击、击退、附带状态。结算顺序固定：

```
基础伤害 → 来源增伤（模块等级、羁绊、神器） → 暴击 → 克制（护甲 / 护盾 / 群体） → 元素反应 → 扣血 → 记账（按来源模块累计）
```

记账数据给结算页和构筑面板显示“每张卡的伤害占比”。

### 3.3 玩家受伤规则

- 接触伤害按“每个敌人各自 0.6 秒冷却”结算，不再共享全局无敌帧。
- 只有单次伤害 ≥ 最大血量 8% 时，给 0.35 秒无敌。
- 被围的扣血随敌人数量上升，但有上限：每秒接触伤害最多为最大血量的 18%，避免被围瞬间秒杀。
- 新增“鲸口吞弹”：挖斗咬合时会吞掉前方的敌方弹道，变成货物（对齐原作 ProjectileAbsorber）。远程敌人的子弹也就成了可以利用的资源。

### 3.4 敌人防御标签

| 标签 | 效果 | 克制 |
|---|---|---|
| 装甲 | 每次伤害减固定值 | 高单发、穿甲 |
| 正面盾 | 正面 120° 减伤 80% | 绕背、侧炮、投掷、爆炸 |
| 群体 | 血少量多 | 范围、穿透、链 |
| 飞行 | 地面效果（地雷、焦油、地震）打不到 | 顶槽、乘员 |

精英和 Boss 可带 1 到 2 个标签，每个阶段的敌人配置要覆盖至少 2 个标签。

### 3.5 新增敌人角色（复用现有模型 + 新道具外观）

| 角色 | 行为 | 给玩家的压力 |
|---|---|---|
| 自爆车 | 冲向玩家，1 秒红圈后爆炸，误伤其他敌人 | 提前清或引到敌群里 |
| 炮台 | 不动，远程抛射，带装甲 | 必须冲进去 |
| 盾兵 | 正面盾，护住身后的远程兵 | 绕背 |
| 号手 | 给周围敌人加速 + 减伤，自身脆 | 优先击杀 |

### 3.6 元素反应（每组都有明确的视觉和音效）

| 组合 | 反应 |
|---|---|
| 潮湿 + 电 | 导电：电伤在潮湿敌人之间连锁 |
| 冰冻 + 重击 / 冲撞 | 碎裂：额外 150% 伤害，解除冰冻 |
| 灼烧 + 油 | 爆燃：小范围爆炸 |
| 减速 + 任意伤害 | 对减速目标增伤 20%（对齐原作 DamageToSlowedEnemies） |

羁绊标签直接对应这四组元素，选卡和战斗打通。

### 3.7 冲撞与重量

- 冲撞伤害 = 车重 × 相对速度系数（对齐原作 AttackModuleRam），冲刺时最高。
- 被击退的敌人撞到别的敌人，双方各受原伤害的 30%（对齐原作 KnockbackCollisionDamage），可以把敌人“打台球”。
- 越重的车撞得越疼，但转向越慢，作为载具之间的取舍。

### 3.8 Boss

- 破韧条：持续伤害累积，满了 Boss 瘫倒 3 秒，受到伤害 +50%。这是玩家主动技能的最佳释放时机。
- 每个 Boss 加 1 个专属招式，不再只靠 8 个通用招式组合。
- Boss 死亡爆炸有伤害上限，不会把濒死的玩家炸死（对齐原作 BossDeathDamageCap）。

### 3.9 节奏目标（用平衡模拟测）

| 指标 | 目标 |
|---|---|
| 蜂群单位 | 任意一次命中即死 |
| 普通小怪 | 1 到 2 秒击杀 |
| 精英 | 8 到 12 秒 |
| 阶段 Boss | 60 到 90 秒，其中破韧 2 到 3 次 |
| 站桩不动 | 阶段高峰期约 8 到 10 秒死亡 |
| 自动攻击 / 主动技能 伤害占比 | 约 70% / 30% |

### 3.10 可读性

- 伤害数字：杂兵受到的伤害按 0.25 秒合并为一个数字，暴击和反应单独显示。
- 颜色规范：敌方弹道一律红橙色，我方一律骨白或元素色。

## 4. 实现批次

| 批次 | 内容 | 验收 |
|---|---|---|
| B1 | 模块自动攻击 + 槽位朝向 + 统一伤害管线 + 来源记账 | 装模块后自动开火；伤害全部走新入口；结算能读到每个模块的伤害 |
| B2 | 受伤规则 + 鲸口吞弹 + 冲撞 / 台球 | 被围扣血随数量上升且有上限；吞弹变货物 |
| B3 | 防御标签 + 4 种新敌人 + 阶段配置 | 每阶段覆盖 2 个以上标签；新敌人行为测试 |
| B4 | 元素反应 + 羁绊对接 | 4 组反应可触发并有表现 |
| B5 | Boss 破韧 + 专属招式 + 死亡伤害上限 | 每个 Boss 至少可破韧 2 次 |

每批结束都跑一次平衡模拟，用 3.9 的指标验收。B1 是系统设计 S1（结算伤害占比）和 S2（羁绊）的前置，建议放在 S1 之前做。

## 5. B1 实现记录（2026-10-11）

| 内容 | 位置 |
|---|---|
| 统一伤害管线：护甲（每次减固定值，最少保留 20%）、受伤倍率、按来源记账（溢出不计）、击杀归属 | `scripts/combat/damage_pipeline.gd`；`EnemyDummy.take_damage(amount, kind_tag, source)` |
| 来源标注：bite / throw / dash / summon / auto:&lt;id&gt; / cast:&lt;id&gt;；弹道和地面区域在创建时记住来源，灼烧记住点火者 | `projectile.gd`、`area_hazard.gd`、`ability_library.gd`、`vehicle_controller.gd`、`main.gd` |
| 40 个模块的自动攻击（10 种开火方式，5 种槽位朝向），顶置炮塔 300°/秒转向、对准 14° 内才开火 | `scripts/combat/auto_weapons.gd` 的 `PROFILES` |
| 卡面第三行写出「自动攻击 · 槽位 · 每 N 秒」 | `selection_ui._describe` |
| 结算页显示本局伤害来源前 5（每张卡自动 + 主动合计） | `m0_hud.damage_report` |
| 验收 | `tests/c29_combat_b1.gd`（已进一键回归） |

自动攻击伤害 = 基础值 × (1 + 模块升级伤害) × (1 + 神器/船长伤害) × 底盘成长（挖斗威力 / 14，封顶 4 倍）；冷却吃神器冷却缩减和模块升级冷却。

8 个种子的整局模拟（随机选卡、只会绕圈的机器人）：

| 指标 | 结果 | 目标 |
|---|---|---|
| 自动 / 主动 伤害占比 | 中位约 73% / 23%（56% 到 87%） | 约 70% / 30% |
| 阶段 Boss 战时长（含清场） | 中位：阶段 1 约 42 秒，2 约 46 秒，3 约 59 秒，4 约 50 秒；偏弱构筑会拖到 140 秒以上 | 60 到 90 秒（B5 加破韧后再收紧） |
| 未标来源伤害 | 0 | &lt; 5% |
| 机器人结局 | 3 胜 5 负，负的 4 局倒在阶段 4 | 阶段 4 对被动打法有压力 |

为配合 Boss 战时长，Boss 血量倍率从 1.5 / 3.5 / 3.8 / 4.0 调到 4.5 / 9.5 / 9.0 / 8.0，Boss 伤害倍率从 1.0 / 1.3 / 1.5 / 2.0 调到 1.0 / 1.15 / 1.2 / 1.4（`config/stages.json`）。

遗留：挖斗仍然一直生效，没有改成「无前槽武器时兜底」，因为它是主角的身份动作，等 B2 吞弹一起定；挖斗和冲刺的暴击仍在各自代码里判定，没有并进管线。
