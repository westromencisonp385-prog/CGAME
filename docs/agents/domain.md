# Domain Docs

This is a single-context repository.

Before exploring or changing code, read:

- `CONTEXT.md` for the stable project vocabulary.
- Relevant decisions under `docs/adr/` when that directory exists.
- `docs/spec.md` before gameplay changes.
- `docs/assets/production-guide.md` before asset or visual changes.

Use the terms from `CONTEXT.md` in issue titles, tests, and handoff notes. Keep observed reference facts, inferred design proposals, and unknown runtime behaviour explicitly separated.
